# Security

Rydd moves files on your Mac, so problems that could lose, expose or misplace files are taken seriously.

If you find a security issue, please email **hello@tang-spark.no** instead of opening a public issue. Include the steps to reproduce it and the versions of Rydd and macOS. You will get a reply within a few days, and a fix will be released as soon as it is ready.

Rydd makes no network connections, so most reports will be about file handling: moving or trashing the wrong file, overwriting a file, undo not restoring a file, following links unexpectedly, or reading outside the folders the user chose.
