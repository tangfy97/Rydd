# Rydd 用户旅程审查

## 旧流程的问题

| 阶段 | 发生了什么 | 问题 |
|---|---|---|
| 安装后第一次打开 | 没有任何窗口；图标只出现在菜单栏，菜单栏满时还会被收进折叠区 | 用户不知道 App 在哪、有没有打开 |
| 同上 | 立刻扫描 Downloads 和桌面，并启动本地 AI | 没征得同意就开始干活；用户没选过文件夹 |
| 同上 | macOS 弹出“允许访问 Downloads/文稿”的权限框 | 弹框出现时用户不知道为什么 |
| 打开面板 | 数字、文件夹名、按钮、设置开关、说明文字挤在一起 | 信息过载，读起来像 AI 生成的说明书 |
| 整理窗口 | 每行有理由、层级标签、隐私声明 | 重点（文件去哪）被淹没 |
| 语言 | 只有中文 | 英文系统用户看不懂 |

## 新流程

```
第一次打开
  └─ 引导窗口（三步，可返回）
       1 欢迎      App 图标 · 一句话 · “开始使用”
       2 选文件夹  Downloads / 桌面 / 添加其他；默认都不勾选，至少选一个才能继续
       3 就绪      “Rydd 在菜单栏里”的示意 · 本地 AI 开关 · “开始”
  └─ 点“开始”后才扫描；系统权限弹框此时出现，用户刚选过文件夹，知道为什么
  └─ 整理窗口自动打开，显示第一份整理计划

之后
  菜单栏图标：抽屉拉开 + 数字 = 有文件待整理；合上 = 都整理好了
  点图标：原生菜单 —— 查看 N 个文件… / 撤销上次整理 / 重新扫描 / 设置… / 退出
  整理窗口：原生表格（勾选 · 名称 · 移到）→ “整理 N 个文件” → 可撤销
  设置：标准设置窗口，“通用”与“文件夹”两个标签页；系统设置风格的图标行；文件夹列表下方 +/−
  后台：只在用户选过的文件夹变化后重新扫描，不弹通知
```

## 原则

- 用户点“开始”之前，不读取任何文件夹。
- 每个画面只回答一个问题：引导页回答“要整理哪里”，面板回答“现在有几个”，整理窗口回答“都去哪”。
- 不出现解释性文字；判断依据只在鼠标悬停时显示。
- 只用系统控件：原生菜单、表格、复选框、弹出按钮、设置标签页；系统字体和用户的强调色。
- 中英文跟随系统语言。
